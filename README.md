- 🔐 **Focusing on:** Binary exploitation, reverse engineering, and cryptographic protocols.
- 📡 **Safetrack (EPICS Gold I):** Developing a low-cost mesh networking safety system using **LoRaWAN**, GPS integration, and embedded systems for vulnerable rural communities.
- 🤖 **Mentorship:** Leading peer-to-peer academic support for the Sun Devil Robotics Club.
- 🚦 **Hardware:** Designed and simulated a 4-bit microprocessor architecture and synchronous traffic light systems (Logisim/Verilog).
